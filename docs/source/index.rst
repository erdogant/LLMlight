*LLMlight* is a Python package for running Large Language Models (LLMs) locally with minimal dependencies. It provides a simple interface to interact with various LLM models, including support for GGUF models and local API endpoints.


.. tip::
	`Medium Blog: How To Build Your Language Model: Local, Private, and Specialized for Specific Tasks. <https://erdogant.medium.com/>`_

-----------------------------------

.. note::
	**The LLMLight library is for free but powered by caffeine!** Like it? Chip in what it's worth ❤️ and keep me developing cool stuff that you can use!

.. code-block:: console

   pip install LLMlight
